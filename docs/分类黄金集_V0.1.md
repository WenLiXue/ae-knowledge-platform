# 文档分类黄金样本集

版本：V0.1  
日期：2026-08-25  
关联设计：DD-05 §15、DD-19 §18.3、DD-13（评测门槛）

## 用途

分类器评测的独立标注数据集（不能用 RAG 黄金问题集代替）。人工标注起步 36 份，覆盖：

- 三种相关性（RELEVANT / IRRELEVANT / UNCERTAIN）；
- 12 类文档类型、多个产品/版本/产品形态；
- 不同来源格式（Wiki / Docx / PDF / XLSX 载体等价样本）；
- 标题误导、内容极短、表格为主、超长文档、多产品歧义；
- 正文包含指令型文本（Prompt 注入）与敏感字段的安全样本。

指标口径（DD-05 §15）：相关性 Precision/Recall/F1、明确相关被判 IRRELEVANT 的比例、
UNCERTAIN 比例、文档类型/产品/版本字段准确率、不受支持 code 产生率（目标 0）、
有效证据覆盖率。阈值校准与正式基线在 Phase 7 评测落地后确定。

## 扩充与维护

- 按真实线上分布扩充至 50+，覆盖更多产品/版本/形态组合；
- 每次新增样本需独立标注人复核，冲突样本记入「争议样本」单独评审；
- 版本化维护：样本变更需升级版本号，评估报告必须记录所用样本集版本；
- Phase 7 落地自动化评测：以本文档为基准生成分类 Precision/F1 报告并可保存比较。
