# 项目文档目录

本目录保存 AE Knowledge Platform 的需求、设计、原型和项目过程资料。

## 目录结构

- `产品知识查询_V1需求基线.md`：V1 需求基线
- `产品知识智能平台_PRD_v1.0.md`：早期 PRD 版本
- `产品知识智能平台_PRD_v1.1_需求分析版.md`：需求分析版 PRD
- `AE内部知识平台_V1_概要设计_V1.0.md`：概要设计
- `详细设计/`：后端、数据模型、文档治理、检索问答、Agent、部署和测试等详细设计
- `详细设计/22_工具型任务Agent详细设计_V0.1.md`：工具型 Agent 架构、工具契约、Planner、执行、安全与持久化设计
- `详细设计/23_工具型任务Agent实施规划与验收_V0.1.md`：分阶段实施任务、测试命令、灰度、回滚与验收矩阵
- `详细设计/24_交给实现Agent的完整提示词_V0.1.md`：可直接复制给其他实现 Agent 的主提示词、执行规则和交付模板
- `prototypes/`：HTML 原型、视觉方向、交互说明及相关素材
- `RAG业务黄金问题集_V0.1.md`：检索问答评测样本
- `现有工程调查与API实现差距分析_2026-08-24.md`：现有工程调查与复用边界
- `项目交接与后续执行计划_2026-08-18.md`：阶段交接与后续执行计划

## 文档维护约定

1. 需求、设计和验收规则随代码一起版本化。
2. 发生重大设计变更时，优先更新对应文档，再修改实现。
3. 已废弃或历史版本保留原文件，不直接删除；在文档中标注状态和替代版本。
4. 原型素材与原型说明放在 `prototypes/` 下，避免散落在代码目录。
