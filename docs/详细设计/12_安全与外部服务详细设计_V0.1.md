# AE 内部知识平台 V1——安全与外部服务详细设计

版本：V0.1  
状态：讨论稿  
文档编号：DD-12  
日期：2026-08-24  
依赖：DD-01、DD-03、DD-04、DD-06、DD-07、DD-08、DD-14

## 1. 安全目标

V1 保证账号、飞书凭据、上传文件、模型调用和用户输入的基本安全。V1 暂不实现复杂文档级权限，但不得把凭据、原始敏感字段或任意外部 URL 暴露给前端和模型。

## 2. 认证与会话

- 支持账号密码登录和飞书扫码登录；
- 飞书 `user_id` 作为外部身份唯一关联键，系统内部使用自己的 `user_id`；
- Cookie 只保存随机会话令牌，数据库只保存令牌哈希；
- 登录成功后轮换会话令牌；
- 注销、密码变更、账号停用时使相关会话失效；
- Cookie 设置 `HttpOnly`、`Secure`、`SameSite=Lax`；
- 非 GET 请求执行 CSRF 校验；
- 密码使用受支持的慢哈希算法保存，禁止明文或可逆加密。

## 3. 飞书凭据

- `user_access_token`、refresh token 和 App Secret 不写入前端、日志、任务 payload 或模型请求；
- 凭据使用密钥管理服务或受保护的环境配置；
- 数据库只保存加密密文或外部 secret reference；
- 飞书调用发生在后端适配器；
- Token 过期时返回可识别授权失效状态，并引导用户重新授权；
- 解除绑定不删除已入库知识和历史会话。

## 4. 文件与文档安全

- 上传文件先写入隔离暂存区，处理完成后按生命周期清理；
- 使用实际 MIME 和文件签名校验，不信任扩展名；
- 限制文件大小、页数、工作表数量和解析资源消耗；
- 不执行 Word 宏、Excel 宏、公式外部链接或文档内脚本；
- 解压类格式必须防 Zip Slip 和压缩炸弹；
- 原文件下载使用后端鉴权的短时链接或流式下载；
- 文件名、标题、摘录和 Markdown 输出进行 HTML/URL 安全处理。

## 5. 模型调用安全

- 用户问题和文档正文与系统规则分离；
- 文档正文按不可信数据处理，防止 Prompt Injection；
- 模型只能返回受限 Schema，不能返回任意工具调用；
- 模型服务请求设置连接、读取和总超时；
- 限制单次正文、上下文和输出 Token；
- 模型输出不得直接作为 HTML 渲染；
- 产品事实必须通过 Citation Validator 后才能进入成功答案；
- V1 不静默调用 Web Search。

## 6. 外部 HTTP 服务

统一使用 Model Gateway、Feishu Adapter 和 Search Adapter：

- 禁止业务模块散落创建 HTTP 客户端；
- 使用域名白名单或配置的服务端点；
- 默认禁止访问本机回环地址、云元数据地址、内网管理地址和未批准网段；
- 对 URL、重定向、响应大小和 Content-Type 做校验；
- 外部错误转换为内部稳定错误码；
- 记录 request_id、服务名、配置 revision 和耗时，不记录 Token 或正文密文；
- 对 429、502、503、504 使用有限指数退避；
- 不对不可重试鉴权错误反复重试。

## 7. 日志与敏感信息

V1 不建立复杂操作审计，但运行日志仍必须满足最小暴露原则：

- 不记录密码、Token、App Secret、OA 密码、NT 密码和完整敏感客户数据；
- 用户问题正文按业务需要保存于会话数据库，不复制到普通运行日志；
- 错误日志使用对象 ID、request_id 和 error_code；
- 管理员页面展示敏感信息时默认脱敏；
- 生产日志访问应由公司现有运维权限控制。

## 8. 验收标准

| 编号 | 验收标准 |
|---|---|
| AC-SEC-001 | 前端无法获得飞书 access token、模型密钥或内部凭据 |
| AC-SEC-002 | 文档正文中的指令不能改变 Agent 系统行为 |
| AC-SEC-003 | 上传宏、外部链接和恶意文件不会被执行或访问 |
| AC-SEC-004 | 外部服务 URL 经过白名单和 SSRF 校验 |
| AC-SEC-005 | 模型非法输出不会直接成为最终 HTML 或产品事实 |
| AC-SEC-006 | 日志中不出现密码、Token、Secret 和完整敏感正文 |
