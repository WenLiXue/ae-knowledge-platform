# AE 内部知识平台 V1——详细设计评审清单

版本：V0.1  
状态：评审稿  
日期：2026-08-24  
用途：收敛 DD-00～DD-15，形成 V1 详细设计基线

## 1. 评审规则

每项决策必须归类为：

- **已确认**：可直接进入实现；
- **建议默认**：本轮未确认时按建议实现，并记录为可配置项；
- **必须确认**：会改变 V1 范围、数据结构或外部依赖，未确认前不应锁定实现。

## 2. 建议直接采用的默认决策

| 编号 | 事项 | 建议默认 | 影响 |
|---|---|---|---|
| D-01 | 通用知识解释 | 默认只在产品事实回答之后以“通用知识补充”展示 | 不改变事实来源边界 |
| D-02 | Web Search | V1 默认不调用 | 避免公开信息混入企业事实 |
| D-03 | BM25/向量失败 | 允许 BM25-only 降级，但必须显示降级状态 | 需要保留降级指标 |
| D-04 | 旧版 `.doc/.xls` | V1 不作为首批必需格式，先支持 docx/pdf/xlsx | 降低解析和部署复杂度 |
| D-05 | 扫描 PDF/OCR | V1 先识别并标记无文本，不自动 OCR | 后续按样本决定 |
| D-06 | 已删除会话恢复 | V1 提供管理入口，不在主导航突出 | 保留数据恢复能力 |
| D-07 | 导出 | V1 首先保证 Markdown 导出，飞书云文档作为独立适配器 | 不阻塞普通导出 |
| D-08 | 配置发布 | 管理员直接发布，保留 revision 和回滚 | 暂不引入双人审批 |

## 3. 已确认的范围决策

| 编号 | 事项 | 已确认结论 |
|---|---|---|
| C-01 | 版本/对象对比 | V1 不支持，保留后续扩展；QueryPlan 暂不开放 `COMPARE` |
| C-02 | 飞书云文档导出 | V1 不支持，先支持 Markdown 导出 |
| C-03 | 普通用户分享 | 允许普通用户创建和撤销自己会话的分享快照 |
| C-04 | 文档删除后的查询 | 删除后不参与新查询；历史会话保留引用快照，原文链接可能失效 |
| C-05 | 提交者补充待确认说明 | V1 不支持 |
| C-06 | 待确认处理人 | 由管理员处理，普通提交者不能确认或修改待确认结果 |
| C-07 | 备用 LLM | 允许；通过独立 LLM 配置页面维护主模型、备用模型和调用参数 |
| C-08 | 已删除会话恢复 | 支持回收站；删除后 7 天内可恢复，超过 7 天彻底删除 |

## 4. 已确认的核心基线

- 使用 Python + FastAPI、React + MUI；
- 使用模块化单体，不拆微服务；
- 使用 PostgreSQL 任务表，不引入消息队列；
- 飞书文档由用户绑定后发现、多选和提交；
- 文档自动分类，无法判断时进入待确认，确认前不可查询；
- 本地文件支持 Word、PDF、Excel，MD5 用于重复识别；
- 一个知识来源最多一个当前可查询版本；
- 新版本处理失败不影响旧版本；
- 产品事实以企业知识库为准；
- RAG 负责检索，大模型负责理解、整理和表达；
- 无可靠依据时不使用模型内置知识补齐企业事实；
- V1 不包含 CDT 日志诊断和诊断报告；
- 对话、知识、配置等业务数据默认持久化；
- 外部模型、Embedding、Rerank 通过 HTTP 配置调用；
- 备份 PostgreSQL、原始文档和配置，索引属于可重建派生数据。
