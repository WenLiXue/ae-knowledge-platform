# AE 内部知识平台 V1——系统管理与运营详细设计

版本：V0.1  
状态：讨论稿  
文档编号：DD-11  
日期：2026-08-24  
依赖：DD-02、DD-03、DD-06、DD-08、DD-09、DD-14

## 1. 设计目标

系统管理面向知识库负责人和管理员，提供用户、文档、任务、配置和运行状态管理。管理页面只操作领域服务，不直接修改数据库状态。

## 2. 管理范围

| 模块 | V1 能力 |
|---|---|
| 用户管理 | 查看、启用/停用账号、查看登录方式和飞书绑定状态 |
| 知识库管理 | 查看文档状态、来源、分类、版本、当前可查询状态 |
| 分类确认 | 处理分类器返回的 UNCERTAIN 文档 |
| 任务管理 | 查看任务、失败原因、重试和取消待处理任务 |
| 配置管理 | 产品、大版本、小版本、文档类型、来源优先级、LLM/Embedding/Rerank 配置引用 |
| 运行概览 | 查询量、反馈、无结果问题、文档任务和外部依赖状态 |
| 数据维护 | 触发元数据重建、索引校验和孤儿数据清理 |

不包含：CDT 诊断管理、复杂文档级权限、自动修改分类体系、直接修改生产数据库。

## 3. 管理命令与状态

### 3.1 文档管理

- 查看文档详情；
- 修改分类、产品、版本和文档类型；
- 触发重新分类；
- 重试失败任务；
- 处理待确认分类；
- 标记无关；
- 维护来源优先级。

文档的状态转换仍由 Knowledge Domain 执行，管理端不能绕过状态机直接把文档改为 READY。

### 3.2 任务管理

任务列表支持按类型、状态、来源、创建时间和错误码筛选。人工重试创建新任务并保留 `parent_task_id`，不覆盖旧任务执行记录。

人工重试前必须检查：

- 来源仍然存在且未下线；
- 上游版本没有被新的成功版本替换；
- 任务类型仍在当前配置中启用；
- 不存在同一业务对象的有效运行任务。

## 4. 配置发布

配置采用草稿、校验、发布、回滚的流程：

```text
编辑草稿 → Schema 校验 → 引用完整性校验 → 发布新 revision → 新任务读取新 revision
```

发布规则：

- 已运行任务绑定创建时的配置快照；
- 新配置不回溯改变已完成文档；
- 分类配置修改后不自动重分类全部历史文档；
- 来源优先级配置必须保证存在默认顺序且无循环引用；
- 模型配置只保存模型连接信息和密钥引用，不显示密钥明文；
- 左侧保留独立的“LLM 配置”页面，页面内部使用“模型管理”“服务配置”两个 Tab；
- “模型管理”维护名称、模型类型、协议、Endpoint、Model 名称、密钥和启用状态；“服务配置”维护问答、分类、Embedding、Rerank 与模型配置的绑定；
- V1 不强制配置主备模型，不向管理员展示超时、重试、温度、Top P 等技术参数；备用模型作为未来可选高级能力；
- 每次业务调用保存实际使用的模型配置 ID 和配置 revision，供回答追踪和黄金问题评测；
- 具体字段、交互、API、迁移和验收规则见 DD-20；
- 发布失败不改变当前生效 revision。

## 5. 运营指标

### 5.1 查询指标

- 查询总量；
- 活跃用户数；
- 有帮助/没有帮助比例；
- 无结果问题数量；
- 低满意度问题；
- 平均和分位响应时间；
- 生成失败和检索降级数量。

### 5.2 知识库指标

- 文档总量及各状态数量；
- 飞书同步成功/失败数量；
- 解析失败数量；
- 分类待确认数量；
- 索引成功率；
- 长期未更新文档数量；
- 当前 READY 版本数量。

### 5.3 依赖健康

展示飞书、对象存储、PostgreSQL、检索引擎、LLM、Embedding 和 Rerank 的最近探活结果、错误率和最近失败时间。探活不得调用真实大模型生成业务答案，使用轻量健康接口或受控测试请求。

## 6. 统计口径

- 查询量按成功创建的 UserMessage 统计，重复幂等请求不重复计数；
- 反馈按当前回答反馈记录统计；
- 无结果按 `answer_type=INSUFFICIENT` 统计；
- 低满意度按 `NOT_HELPFUL` 统计；
- 文档成功按当前版本进入 READY 统计；
- 任务成功率按终态任务统计，不把重试次数误算成独立业务任务；
- 所有指标保留来源时间窗口和配置 revision。

## 7. 验收标准

| 编号 | 验收标准 |
|---|---|
| AC-ADM-001 | 管理员可以查看文档、任务和配置的当前状态 |
| AC-ADM-002 | 失败任务可人工重试，且旧任务历史不被覆盖 |
| AC-ADM-003 | 配置发布前完成 Schema 和引用校验 |
| AC-ADM-004 | 配置发布失败不改变当前生效版本 |
| AC-ADM-005 | 查询、反馈、无结果和任务统计口径一致 |
| AC-ADM-006 | 运行概览可以区分依赖不可用、检索降级和答案生成失败 |
